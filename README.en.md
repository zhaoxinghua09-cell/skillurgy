**Skillurgy** is the methodology for creating AI skills. A skill (e.g. `SKILL.md`) is an autonomous unit governed by three laws — **Registered** (naming and description), **Verified** (capability claims testable), **Gated** (loading and change controlled). Five properties: pluggable, verifiable, unloadable, auditable, evolvable.

## When to use

Use when creating, governing, or evaluating AI skills (SKILL.md) with pluggability, verifiability, and auditability.

## Definition

A skill is a reusable, governable, cross-platform autonomous unit (30+ platforms), distinct from one-off prompt engineering. It must be registered, its capability claims must be testable, and its loading/change must be gated.

## Verification

Prior-art search v2: zero conflicts. Distinct from prompt engineering: a skill is a reusable, governable, cross-platform autonomous unit.

## Examples

Three-law five-property checklist:

```markdown
- [ ] Registered: unique name + clear description
- [ ] Verified: each capability claim is testable/falsifiable
- [ ] Gated: loading and change controlled, versioned
- [ ] Pluggable: drop into skills dir, unload by removal
- [ ] Unloadable: no persistent side effects
- [ ] Auditable: every call leaves a reviewable record
- [ ] Evolvable: capabilities versionable
```
