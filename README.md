# Skillurgy · 技能工程术

> 主张：技能生产有纪律——可插拔、可验证、可卸载、可审计、可演进
> 家族：LGD 创造术元层（-urgy）｜ 状态：占位声明（查重全维度 0 占用，R1+R2）

## 定义
创造 AI 技能的方法论：技能（SKILL.md 等）是自治之物，适用三律——有籍（命名与描述注册）、有证（能力声明可验证）、有门禁（加载与变更受控）。技能工程五性：可插拔/可验证/可卸载/可审计/可演进。

## 与 prompt engineering 的区隔
prompt 是单次交互指令；技能是可复用、可治理、可跨平台（30+ 平台）的自治单元。
